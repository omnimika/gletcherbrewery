# ADR 0000: базовое приложение Next.js

Дата: 2026-10-31. Статус: **Confirmed** для явно заказанного технического стека.

## Контекст и решение

Пользователь разрешил инициализировать существующий репозиторий, сохранив
пользовательские файлы, без интеграций, commit и push. Использован официальный
`create-next-app` 16.4.3 во временной папке с `--disable-git` и `--skip-install`;
в репозиторий перенесены только новые файлы приложения и конфигурации.

**Confirmed:** Next.js 16.4.3 (стабильный npm dist-tag `latest` на момент
инициализации), App Router, TypeScript strict, Tailwind CSS, ESLint,
`src/`, alias `@/*`, npm и lockfile. Приложение содержит минимальную
стартовую страницу Gletcher Brewery; перенос контента ещё не выполнен.
`agentRules: false` отключает автоматическое редактирование существующего
`AGENTS.md` при запуске `next dev`.

## Зависимости и сопровождение

| Зависимости | Причина выбора и альтернативы | Влияние и сопровождение |
| --- | --- | --- |
| `next`, `react`, `react-dom` | Запрошенный Next.js и его React runtime. Другой framework выходит за рамки задания. | Node.js для сервера; внешние сервисы не требуются. Версии обновлять совместно с проверкой сборки. |
| `typescript`, `@types/node`, `@types/react`, `@types/react-dom` | Strict TypeScript и типы используемой платформы. JavaScript не соответствует заданию. | Только разработка и сборка; обновлять с typecheck. |
| `tailwindcss`, `@tailwindcss/turbopack` | Tailwind CSS 4 и официальный адаптер из текущего шаблона Next.js. PostCSS — альтернатива при смене сборщика. | Только сборка; адаптер привязан к Turbopack. Новая инфраструктура не нужна. |
| `eslint`, `eslint-config-next` | ESLint 9 с правилами Next.js, React и TypeScript, как в официальном шаблоне. Транзитивные плагины `import`, `jsx-a11y` и `react` пока не заявляют поддержку ESLint 10. Biome не соответствует явно выбранному ESLint. | Только разработка; зависимости требуют Node.js 20.19+, 22.13+ либо 24+. ESLint 9 помечен npm как устаревший; переход на 10 — после совместимости плагинов. |

Точные установленные версии и транзитивные зависимости фиксирует
`package-lock.json`. Установка воспроизводится через `npm ci`.

**Open:** `npm audit` на дату инициализации сообщает об умеренной уязвимости
`minimatch` в цепочке lint-зависимостей
([GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249)).
Она относится к обработке glob-шаблонов инструментами разработки.
Обновление ESLint до 10 её не устраняет и создаёт конфликт peer dependencies
плагинов. Не применять `npm audit fix --force` или подмену `minimatch` на другую
major-версию без проверки совместимости. Production-зависимости по проверке
`npm audit --omit=dev` не содержат известных уязвимостей.

## Границы и последствия

**Proposed:** `src/components`, `src/lib` и `src/types` — начальные границы
организации кода; доменную структуру уточнить при реализации подсистем.

**Open:** ORM, авторизация, CMS, очереди, БД, административные интерфейсы,
карта, платежи и инфраструктура. Эти решения не приняты данным ADR;
соответствующие пакеты и сервисы не добавлены.

Локальные команды приведены в [инструкции разработчика](../development.md).
Официальные источники: [установка Next.js](https://nextjs.org/docs/app/getting-started/installation)
и [create-next-app](https://nextjs.org/docs/app/api-reference/cli/create-next-app).
