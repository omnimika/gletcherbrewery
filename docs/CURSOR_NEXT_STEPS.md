   Прежний self-inert P1 уже исправлен: сохранить portal вне `#site-root`.
3. **R03: UI-переводы.** Подключить `leadForm` messages ко всем видимым и

   Сербский/армянский/грузинский/немецкий пока не публиковать.

## Критерии приёмки

- `npm run lint`, `npm run typecheck`, `npm run build` проходят на поддерживаемом Node.js.
- RU/EN home, listing и detail имеют корректные язык, тексты и metadata.
- Canonical product ID сохраняется при переключении разных slug; неподдерживаемые
  и неопубликованные страницы не рекламируются и корректно обрабатываются.
- Для модалок проверены initial focus, Tab/Shift+Tab, Escape и возврат фокуса
  после разблокировки фона; меню остаётся интерактивным.
- Фильтр после прокрутки показывает начало выбранной категории; визуал сверён
  с исходником на согласованных viewport, включая низкое окно и 200% zoom.
- Отдельно проверить неизвестный URL и global 404: текущий верхний root layout
  возвращает children, а html/body находятся ниже `[locale]`. Валидные страницы
  не доказывают корректность оболочки ошибок.
- Проверены реальные ссылки header/footer; неперенесённые разделы имеют
  согласованные временные переходы либо явно недоступные действия.
- Для серверной проекции подтверждено отсутствие полных переводов в клиентском
  chunk; результаты новой сборки отделены от ранее сохранённых артефактов.

Browser-результаты и визуальный sign-off фиксировать отдельно; green TypeScript
их не заменяет. В `AGENTS.md`/ROADMAP закрывать замечания только с доказательствами.
Коммиты, push, production и установка новых сервисов — по разрешению владельца.
